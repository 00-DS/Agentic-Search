# Agentic Search with Memory — 开发教程

## 关于这套文档

这是一套面向初学者的完整开发教程。无需前端框架、容器化或 AI Agent 框架经验——按照文档逐步操作，即可从零构建一个「带记忆的论文问答助手」。

本项目的架构刻意保持极简：**一个 Python 后端服务 + 两个原生 HTML/JS 前端文件，零构建步骤**。

## 项目简介

**Agentic Search with Memory**：

1. 用户在浏览器中上传论文 PDF
2. 输入问题（如「这篇论文的核心方法是什么」）
3. AI 自主探索论文（定位关键段落、按需读取），展示推理过程，流式输出回答
4. AI 利用 TMT 记忆系统记住用户的研究方向，后续对话中引用历史

## 你将学到什么

| 技术 | 你会用它做什么 | 在哪里学 |
|------|-------------|---------|
| Python | 文档处理工具（PDF → 纯文本）+ Agent 导航工具（`@tool`）+ pytest 测试 | [模块 1](./01-Python文档工具.md) |
| LangGraph + FastAPI | ReAct agent（工具调用 + 条件边）+ HTTP API 服务 | [模块 2](./02-LangGraph-Agent.md) |
| 原生 HTML + JavaScript | 前端界面 + Agent 推理的流式可视化（fetch + DOM） | [模块 3](./03-HTML前端.md) |
| TMT 记忆系统 | L1 事实提取 + L2 会话摘要（前端按钮手动整合） | [模块 4](./04-TMT记忆系统.md) |

## 学习路径

```
模块 1 → 模块 2 → 模块 3 → 模块 4
```

推荐顺序的依据：

1. **模块 1（Python 文档工具）** — 先实现最底层的能力：把 PDF 转成完整纯文本，并用 `@tool` 装饰器实现四个论文导航工具（`list_papers`/`read_paper`/`search_papers`/`extract_abstract`）。这是整个系统的地基，后续所有模块都依赖它。
2. **模块 2（LangGraph Agent）** — 在文档能力之上构建「大脑」：用 LangGraph 把模块 1 的四个工具组装成 **ReAct agent**——LLM 自主调这些工具探索论文，读哪篇、读哪段都由它当场决定，并用 FastAPI 把它暴露为 HTTP API。
3. **模块 3（HTML 前端）** — 大脑就绪后，再做让用户交互的界面：原生 HTML + fetch 调用上面的 API，看到流式回答。
4. **模块 4（TMT 记忆系统）** — 最后给 Agent 装上「记忆」：L1 每轮自动提取事实，L2 由前端按钮手动触发整合。

## 开始之前

### 你需要准备的

1. **一台电脑**：Windows / macOS / Linux 均可
2. **命令行基础**：会 cd、ls（或 dir）即可
3. **一个现代浏览器**：Chrome / Edge / Firefox 任一，用于运行前端
4. **一个 LLM API Key**：推荐注册 [DeepSeek](https://platform.deepseek.com/)（有免费额度）
5. **一个代码编辑器**：推荐 [VS Code](https://code.visualstudio.com/)
6. **MongoDB Community Server**：数据库引擎，本项目所有数据（记忆、文档）都存入 MongoDB
7. **MongoDB Compass**：MongoDB 自带的图形化数据库查看工具，用于教学调试

### 安装工具链

本项目需要安装两个工具：**uv**（Python 包管理器）和 **MongoDB**（数据库）。本项目的所有数据——包括 AI 的记忆（L1/L2）和上传论文转出的完整 Markdown——都存储在 MongoDB 中，不再依赖任何本地文件。

#### uv（Python 包管理器）

uv 是 Python 的现代包管理器，速度快、自带虚拟环境管理。后端的全部依赖（FastAPI、LangGraph、pymupdf、pytest 等）都由它安装。

- 安装指南：https://uv.oaix.tech/getting-started/installation/
- 安装后验证：打开命令行，输入 `uv --version`，看到版本号即成功

#### MongoDB Community Server（数据库引擎）

MongoDB 是一个文档型数据库，以灵活的 JSON 风格文档存储数据。本项目的记忆数据（L1 事实、L2 会话摘要）和论文 Markdown 全文都存入 MongoDB。

- 下载地址：https://www.mongodb.com/try/download/community
- 安装时保持默认端口 **27017**
- 安装后验证：打开命令行，输入 `mongod --version`，看到版本号即成功
- 默认安装后会以后台服务方式运行；如果未自动启动，可手动运行 `mongod`

> 后端通过 PyMongo（MongoDB 的 Python 驱动）连接 `mongodb://localhost:27017`，数据库名为 `agentic_search`。这些配置在模块 1 中讲解。

#### MongoDB Compass（数据库可视化工具）

Compass 是 MongoDB 官方的图形化客户端，让你像浏览文件一样查看数据库里的集合（collection）和文档（document）。在本教程中，每完成一个数据操作后，都可以用 Compass 直观地确认「数据真的写进去了吗」。

- 安装 MongoDB Server 时通常会自动勾选安装 Compass；若没有，可单独下载：https://www.mongodb.com/try/download/compass
- 打开后默认连接 `mongodb://localhost:27017`，即可看到本项目的 `agentic_search` 数据库

#### 前端如何运行（无需安装）

前端只有两个文件（`frontend/index.html` + `frontend/app.js`），无构建步骤，二选一运行：

- **方式 1（最简单）**：在浏览器中直接打开 `frontend/index.html`
- **方式 2（推荐，便于跨服务请求）**：用 Python 自带的静态服务器托管
  ```bash
  cd frontend && python -m http.server 3000
  ```
  然后访问 http://localhost:3000

### 准备 LLM API Key

在本项目中，LangGraph Agent 和 TMT 记忆系统都需要调用 LLM。你需要一个 API Key。

如果你使用 DeepSeek：

1. 注册 https://platform.deepseek.com/
2. 在 API Keys 页面创建一个 Key
3. 保存好这个 Key，后续配置中会用到
